# spicule

Analog circuits in Python, written out for Spectre simulation and Calibre LVS.

```python
import spicule.hdl as h
from spicule import sim
from spicule.dialects import cdl, spectre
from spicule.hdl.builtins import spectre as sp

nch = h.External("nch", h.MOS, "d g s b")
pch = h.External("pch", h.MOS, "d g s b")


class inv(h.Subckt):
    a, y, vdd, vss = h.Ports(4)
    nfin = h.Param(2)
    mp = pch(nfin=2 * nfin)(d=y, g=a, s=vdd, b=vdd)
    mn = nch(nfin=nfin)(d=y, g=a, s=vss, b=vss)


class tb(h.Subckt):
    vdd, a, y, gnd = h.Signals(4)
    dut = inv(nfin=4)(a, y, vdd, gnd)
    vs = sp.vsource(type="dc", dc=0.8)(vdd, gnd)
    cl = sp.capacitor(c=1e-15)(y, gnd)


lvs = cdl.write(h.elaborate(inv))

run = sim.Simulation(
    h.elaborate(tb),
    top="tb",
    ground="gnd",
    includes=[sim.Include("models.scs", section="tt")],
    analyses=[sim.Analysis("tr", "tran", stop=1e-9)],
)
print(spectre.write(run))
```

```text
    parameters nfin=2

    mn (y a vss vss) nch nfin=nfin

// top: tb
dut (a y vdd 0) inv nfin=4
vs (vdd 0) vsource type=dc dc=800e-3

tr tran stop=1e-9
```

## Layout

| Layer | Holds | Depends on |
| --- | --- | --- |
| `spicule.hdl` | What designers write: subckts, nets, parameters, generators | `ir` |
| `spicule.ir` | The resolved circuit: frozen dataclasses and a validator | nothing |
| `spicule.sim` | What to do with a circuit: includes, options, analyses | `ir` |
| `spicule.dialects` | Text formats: `spectre`, `cdl`, `jsonio` | `ir`, `sim` |
